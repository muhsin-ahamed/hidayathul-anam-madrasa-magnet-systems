# Student Portal

A responsive Flutter Web app for a school student portal.

## Features

- Role-based Student and Admin login
- Student dashboard, results, notes, hall ticket, and profile pages
- Admin dashboard, students, results, notes, hall tickets, announcements, and settings
- Dummy data only
- Material 3 light theme with responsive desktop, tablet, and mobile layouts

## Run

```bash
flutter run -d chrome
```

For a browser-independent local server:

```bash
flutter run -d web-server --web-port 8081
```
